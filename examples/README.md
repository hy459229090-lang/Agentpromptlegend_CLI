# examples

Safe examples for players and implementers.

- `config/`: provider configuration examples with no real API keys.
- `traces/`: synthetic battle traces for replay and tests.
- `ouro-*.svg`: README media captures for the storefront hero, screenshot wall,
  weapon gallery, battle canvas, decision focus HUD, and after-action report.
  They stay storefront-friendly while being derived from mock CLI output, and
  the storefront/screenshot wall mirrors current battle cue tags such as
  `VOX [INTERRUPT]` and `ENM [HIT]`.
