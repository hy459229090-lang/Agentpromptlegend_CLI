# examples

Safe examples for players and implementers.

- `config/`: provider configuration examples with no real API keys.
- `traces/`: synthetic battle traces for replay and tests.
- `ouro-*.svg`: README media captures for the storefront showcase, storefront
  hero, screenshot wall, weapon gallery, battle canvas, decision focus HUD, and
  after-action report. They stay storefront-friendly while being derived from
  mock CLI output, and the showcase/storefront/screenshot wall mirrors current
  battle cue tags such as `VOX [INTERRUPT]`, `ENM [HIT]`, `WINDOW PRESSURE`,
  language switching, and the mock `Play Now` command.
