# 最终产品验收审计

> 日期：2026-06-01  
> 目标：把“成熟游戏化重设计与重构”拆成可证明的验收面，避免凭感觉宣布完成。  
> 当前结论：MVP release candidate 证据充足；完整目标仍保持 active，尚不标记 complete。

## 1. 审计范围

本审计按用户目标和 `AGENTS.md` 规则拆出以下验收面：

1. 核心玩法保持不变：单人 CLI、一个配置英雄、战斗中玩家不选技能或目标、模型只选 action、本地引擎裁判伤害和胜负。
2. 成熟游戏化体验：美术/TUI、战斗演出、剧情文案、世界观、数值、Build、Boss、失败复盘和长期成长都能被玩家感知。
3. 研发架构：Provider、Engine、TUI、Content、Trace、Sessions 分层清楚，可测试、可扩展、可回放。
4. 发布交付：可安装、离开源码目录可试玩、mock 无网络、Provider 配置安全、证据链可复验。

3. 工作树仍有大量未提交变更和 untracked 文件；已新增 `docs/engineering/CHANGESET_MANIFEST_20260601.md` 作为提交边界清单，并提供 `scripts/release_scope.py --stage-plan` 输出只读 staging plan；正式 tag 前仍需人工 review、staging 和 commit。
4. 真实 Provider 联通 smoke：live smoke 不能在无用户密钥环境中作为强证据；当前只能证明 adapter 单测、配置路径、`scripts/provider_smoke.py` 的不联网 preflight/live-smoke 入口，以及 `docs/engineering/PROVIDER_LIVE_SMOKE_20260601.md` 的 pending 记录模板。
