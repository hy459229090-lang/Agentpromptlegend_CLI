# G03 英雄构筑与装备词条策划案

> 状态：v0.1 草案  
> 依赖：设计基线、G02 战斗系统

---

## 1. 模块目标

让玩家在战斗外构筑英雄 Agent。构筑不仅改变数值，也改变模型的选择倾向和可触发效果。

---

## 2. Build 组成

Build 包含：

1. 英雄职业。
2. 技能组。
3. 装备。
4. 词条。
5. 羁绊 / 回响。
6. 英雄 Prompt。
7. 已解锁图鉴信息。

---

## 3. 英雄设计

MVP 最终目标 3 个英雄，但第一轮实现可先做 1 个。

| 英雄 | 风格 | 默认倾向 |
|------|------|----------|
| 暗影学徒 | 法术、腐化、风险收益 | 优先处理高威胁后排 |
| 灰烬守卫 | 防御、反击、稳定 | 优先保命和承伤 |
| 裂弦猎手 | 高速、流血、补刀 | 优先打断和收割 |

---

## 4. 装备三档

| 档次 | 设计 |
|------|------|
| 普通 | 稳定数值，便于理解 |
| 英雄 | 数值更高，固定触发条件 |
| 传奇 | 数值更高，允许模型在限定选项中选择适配效果 |

传奇装备必须写清 `allowed_effects`，不能让模型自由发明。

---

## 5. 词条设计

词条可以来自装备、奖励、事件或污染。

| 词条类型 | 示例 |
|----------|------|
| 数值词条 | 暗影伤害 +10% |
| 行为词条 | 更倾向于先观察未知敌人 |
| 风险词条 | HP 低于 40% 时伤害提升但防御下降 |
| 污染词条 | 死亡复活后获得负面 Prompt 约束 |
| 标签词条 | 增加 `corruption` 标签，触发羁绊 |

---

## 6. 羁绊 / 回响

羁绊由有限标签触发，效果固定。

示例：

| 羁绊 | 条件 | 效果 |
|------|------|------|
| 腐化学派 | `corruption` 标签达到 3 | 毒/腐化伤害提升，敌人中毒时英雄获得护盾 |
| 猎杀仪式 | `execute` 标签达到 2 | 攻击低血量敌人时追加伤害 |
| 黑烛契约 | `sacrifice` 标签达到 2 | 消耗 HP 使用技能时获得额外 power |

Prompt 可被系统解析成标签，但不能由玩家直接声明标签生效。

---

## 7. 验收标准

1. 至少 1 个英雄可用。
2. 至少 3 个技能、3 件装备、3 个词条可用。
3. 装备和词条能影响战斗结算。
4. 至少 1 个羁绊能触发。
5. Build 变化能反映到模型行动上下文中。
