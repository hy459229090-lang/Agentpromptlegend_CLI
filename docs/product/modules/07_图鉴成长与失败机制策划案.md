# G07 图鉴、成长与失败机制策划案

> 状态：v0.2 草案
> 依赖：G04 关卡路线、G05 BattleLLMSession、G08 内容数据、G10 数值平衡
> 本版目标：把怪物图鉴、怪物三档、长期认知成长和失败保留做成后续内容扩展的主轴。

---

## 1. 模块目标

图鉴不是百科页面，而是模型和玩家共同成长的战术记忆。

1. 玩家通过反复遭遇/击败怪物解锁机制认知。
2. 模型只能看到已解锁阶段的信息。
3. 怪物按家族和三档变体扩展，方便后续副本和图鉴成长。
4. 失败后保留图鉴和少量残响，让死亡有意义。

---

## 2. 怪物家族与三档

每个怪物必须先归属一个 `monster_family`，再定义三个档次。

| 档次 | 英文 | 用途 | 数值倍率 | 技能复杂度 | 奖励 |
|------|------|------|----------|------------|------|
| I 碎影 | Trace | 普通怪、教学怪 | 1.0x | 1 个核心动作 | 金币/经验，低概率普通奖励 |
| II 仪式 | Ritebound | 精英怪、宝箱怪 | 1.45-1.75x | 2-3 个动作，带固定机制 | 英雄档奖励概率提高 |
| III 档案化 | Archive-Bound | Boss / Nemesis | 2.6-3.4x | 阶段机制，带图鉴干扰 | 传奇奖励、图鉴突破 |

三档不是单纯改名加血。每一档都必须改变至少一项：

1. 机制。
2. 技能。
3. 图鉴信息。
4. 掉落权重。
5. UI 标识。

## 4. 图鉴阶段

| 阶段 | 条件 | 模型可见信息 | 玩家价值 |
|------|------|--------------|----------|
| 未知 | 首次遭遇 | 名称、外观、基础 HP、档次 | 有神秘感 |
| 观察 | 遭遇 1 次 | 常见技能、伤害类型、是否咏唱 | 可做基础应对 |
| 熟悉 | 击败 2 次 | 抗性、弱点、读条速度、档次差异 | Build 开始有针对性 |
| 掌握 | 击败 5 次 | 完整机制、阶段行为、推荐打法 | 模型能稳定针对 |
| 猎杀 | 击败 10 次 | 特殊克制策略、掉落倾向 | 长期刷怪价值 |

图鉴解锁以 `monster_family` 为主，以 `tier` 为辅。例：掌握黑烛侍祭家族后，模型知道黑烛类敌人通常需要打断；但 III 档 Boss 的阶段机制仍需单独解锁。

## 4.1 图鉴卡片与迷雾

图鉴必须是卡片收藏和战术档案，不是文字列表。

### 未解锁

```text
+------------------------------+
| [??] UNKNOWN FAMILY          |
| tier: ?                      |
| silhouette: ░░░░░            |
| known: first seen in Ash Gate|
| unlock: encounter once       |
+------------------------------+
```

### 观察

```text
+------------------------------+
| [I:k] BLACK CANDLE ACOLYTE   |
| Codex: observed              |
| HP: 50-70     threat: chant  |
| Known                         |
| - Uses delayed shadow chant. |
| Fog                           |
| - ░░░ weakness hidden ░░░    |
| - ░░░ drop table hidden ░░░  |
+------------------------------+
```

### 掌握

```text
+------------------------------+
| [II:k] BLACK CANDLE FIREKEEPER|
| Codex: mastered              |
| Family: Black Candle         |
| Weak: interrupt / silence    |
| Resist: shadow 10%           |
| Drop: candle, control affix  |
| Build hint: Control works.   |
+------------------------------+
```

规则：

1. 未解锁字段用迷雾/占位显示，不能直接消失。
2. 卡片必须显示解锁条件或下一阶段进度。
3. 已解锁图鉴要影响 Prompt 的 `Codex slot` 注入。
4. 图鉴卡片可以在战前预告、Codex 页面和战报中复用。

## 6. 经验成长

经验优先影响 AI 构筑能力，而不是单纯加数值。

| 成长 | 效果 | 优先级 |
|------|------|--------|
| Prompt 容量 | 允许更长英雄 Prompt | P0 |
| 策略槽 | 增加可保留战斗原则 | P0 |
| 上下文预算 | 允许更多图鉴或近期行动进入 BattleLLMSession | P0 |
| 图鉴插槽 | 每场战斗可注入更多已解锁怪物信息 | P1 |
| 少量属性 | HP / MP / speed 小幅成长 | P2 |

### 6.1 Context 窗口成长

经验成长必须显式影响玩家可调整的 Agent context 窗口。

| Level | XP | 解锁 | 玩家感知 |
|-------|----|------|----------|
| 1 | 0 | Prompt style 1、Codex slot 1、Memory 低 | 开局 Agent 粗糙 |
| 2 | 20 | Strategy slot +1 | 可保留一条战术原则 |
| 3 | 45 | Codex slot +1 | 可注入更多怪物卡片 |
| 4 | 75 | Memory Echo +120 | rolling summary 更长 |
| 5 | 110 | Prompt edit budget +1 | 可扩写英雄 Prompt |
| 6 | 150 | Build hint slot +1 | 系统给更多胡牌建议 |

UI 展示：

```text
CONTEXT WINDOW
Strategy    : 2/3 slots
Codex       : 1/2 slots
Memory      : 340/500 echo
Prompt edit : 1/2

Upgrade next:
Level 3 -> Codex slot +1
```

### 6.2 升级选择

升级不能只自动加属性。玩家至少在关键等级选择 context 成长方向：

```text
LEVEL UP :: Agent Context

[1] Strategy Slot +1     keep one more combat principle
[2] Codex Slot +1        inject one more monster card
[3] Memory Echo +120     longer rolling summary

Choose upgrade:
```

这些选择必须影响下一场 BattleLLMSession 的 static context 或 turn delta。

## 7. 失败规则

默认失败：

1. 英雄死亡。
2. 本局结束。
3. 清空本局金币、装备、临时词条。
4. 保留图鉴进度、已发现内容、少量残响货币。
5. 保存死亡 trace 供玩家复盘。

失败结算必须告诉玩家：

1. 死于哪个怪物家族/档次。
2. 本局解锁了哪些图鉴信息。
3. 哪个 Build 选择可能造成风险。

---

## 8. 污染复活

污染复活是暗黑风格的特殊机制，不应默认频繁出现。

触发方式：

1. 传奇装备。
2. 特殊事件。
3. Boss 前稀有选择。

代价：

1. 获得负面 Prompt 约束。
2. 获得污染词条。
3. 后续奖励或图鉴可能被污染。

---

## 9. 验收标准

1. 至少 4 个怪物家族有 I/II 档规划，至少 1 个 III 档 Boss。
2. 怪物图鉴按 family + tier 分阶段解锁。
3. 模型不能看到未解锁图鉴。
4. 死亡后能保留图鉴进度和少量残响。
5. 失败结算能指出怪物档次、死亡原因和可调整 Build 方向。
6. 图鉴 UI 必须使用卡片和迷雾占位，而不是纯文字列表。
7. 经验成长必须至少影响 Strategy slot、Codex slot 或 Memory Echo 中的一项。
