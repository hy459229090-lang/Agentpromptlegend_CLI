# G07 图鉴、成长与失败机制策划案

> 状态：v0.1 草案  
> 依赖：G04 关卡路线、G05 模型行动

---

## 1. 模块目标

让失败和重复游玩有意义。玩家死亡不是单纯清空，而是推动图鉴、解锁和长期理解。

---

## 2. 图鉴阶段

| 阶段 | 条件 | 模型可见信息 |
|------|------|--------------|
| 未知 | 首次遭遇 | 名称、外观、基础 HP |
| 观察 | 遭遇 1 次 | 常见技能、伤害类型 |
| 熟悉 | 击败 2 次 | 抗性、弱点、读条速度 |
| 掌握 | 击败 5 次 | 完整机制、隐藏行为、推荐打法 |
| 猎杀 | 击败 10 次 | 特殊克制策略 |

模型只能看到已解锁阶段的信息。

---

## 3. 经验成长

经验优先影响 AI 构筑能力，而不是单纯加数值。

| 成长 | 效果 |
|------|------|
| Prompt 容量 | 允许更长英雄 Prompt |
| 策略槽 | 增加可保留战斗原则 |
| 上下文窗口 | 允许更多图鉴或近期行动进入模型上下文 |
| 少量属性 | HP / MP / speed 小幅成长 |

MVP 可以先只实现经验数值和升级提示，不做复杂升级树。

---

## 4. 失败规则

默认失败：

1. 英雄死亡。
2. 本局结束。
3. 清空本局金币、装备、临时词条。
4. 保留图鉴进度、已发现内容、少量残响货币。

---

## 5. 污染复活

污染复活是暗黑风格的特殊机制，不应默认频繁出现。

触发方式：

1. 传奇装备。
2. 特殊事件。
3. Boss 前稀有选择。

代价：

1. 获得负面 Prompt 约束。
2. 获得污染词条。
3. 后续奖励或图鉴可能被污染。

示例：

```text
你接受黑烛复活。
HP 恢复至 40%。
新增污染 Prompt：你会更倾向攻击血量最低的敌人，即使它不是最高威胁。
```

---

## 6. 长期保留

| 内容 | 是否保留 |
|------|----------|
| 图鉴进度 | 保留 |
| 已发现装备 | 保留发现记录 |
| 残响货币 | 保留 |
| 本局金币 | 不保留 |
| 本局装备 | 不保留 |
| 本局 Prompt 改动 | 可保存为模板，MVP 可延后 |

---

## 7. 验收标准

1. 战斗后能更新图鉴进度。
2. 死亡后能进入失败结算。
3. 新一局能读取保留图鉴。
4. 模型不能看到未解锁图鉴。
5. 污染复活有明确收益和代价。
