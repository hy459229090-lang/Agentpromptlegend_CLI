# G04 关卡路线、商店与经济策划案

> 状态：v0.1 草案  
> 依赖：设计基线、G01 核心循环

---

## 1. 模块目标

提供肉鸽运营层：玩家通过路线选择决定风险收益，通过商店和奖励调整 Build。

---

## 2. 节点类型

使用设计基线中的 6 类节点：

| 节点 | 设计重点 |
|------|----------|
| 普通怪 | 基础收益，帮助玩家成长 |
| 精英怪 | 高风险，高奖励 |
| 宝箱怪 | 战斗后给构筑选择 |
| 商店 | 安全调整，但放弃战斗经验 |
| 事件 | 给随机性和诅咒空间 |
| Boss | 检验当前 Build |

---

## 3. 路线选择原则

每一层至少给玩家一个有意义选择：

1. 安全 vs 成长。
2. 金币 vs 经验。
3. 立刻变强 vs 长期解锁。
4. 商店调整 vs 战斗掉落。

不要设计只有数值大小差异的路线。

### 3.1 CLI 路线交互规格

默认玩家试玩模式下，路线选择必须停下来等待输入，不能静默选择第一个节点。

```text
ROUTE :: LAYER 2

[1] [M] Hungry Followers       risk: low   reward: gold/xp
[2] [$] Black Candle Merchant  risk: safe  reward: shop, no xp

Choose node (1-2), or q to quit:
```

| 情况 | 处理 |
|------|------|
| 合法数字 | 进入对应节点 |
| `q` | 放弃本局并进入结算 |
| 空输入 | 保持等待，或提示默认选项但不立刻跳过 |
| 非法输入 | 重新显示可选范围 |
| `--auto` / batch | 可自动选择，但屏幕和 trace 必须标记 auto |

---

## 4. 经济资源

| 资源 | 来源 | 用途 |
|------|------|------|
| 金币 | 战斗、宝箱怪、事件 | 商店购买装备、词条、道具 |
| 经验 | 战斗、宝箱怪、Boss | 提升上下文容量、策略槽、少量属性 |
| 残响货币 | 死亡或通关后保留 | 长期解锁，MVP 可只记录不消费 |

---

## 5. 商店功能

商店必须能做：

1. 购买装备。
2. 购买词条或道具。
3. 替换已有装备。
4. 大幅调整英雄 Prompt。

商店不能给战斗经验。选商店就是安全但少成长。

### 5.1 MVP 商店交互

MVP 商店可以不做复杂库存系统，但不能是空壳 start/end。

```text
SHOP :: BLACK CANDLE MERCHANT
Gold: 32

[1] Ash-Steel Blade       18g   weapon  ATK +3, tag: blade
[2] Corrupted Focus       14g   affix   start shield, tag: corruption
[3] Prompt Rite           10g   strategy slot: control
[4] Leave

Choose:
```

购买后必须即时反馈金币变化和 Build/Prompt 变化。Prompt 自由编辑可延后，MVP 先使用预设策略模板。

---

## 6. 战后奖励

战斗胜利后展示奖励：

1. 固定金币。
2. 固定经验。
3. 根据节点类型给奖励选择。

宝箱怪建议给三选一：

1. 装备。
2. 词条。
3. 图鉴/Prompt 相关资源。

### 6.1 奖励选择规格

所有有选择的奖励必须展示至少三类信息：类型、效果、对下一场战斗的影响。

```text
REWARD

[1] Ash-Steel Blade      weapon   ATK +3, basic attack 5 -> 7
[2] Corrupted Focus      affix    start battle with SHD shield(8)
[3] Echo Fragment        archive  codex progress +1

Choose reward (1-3):
```

默认试玩模式下不允许永远 `rewards[0]`。只有 `--auto` 或批量试跑可以自动选择。

---

## 7. 验收标准

1. 新手副本有固定路线。
2. 玩家能选择下一节点。
3. 商店和战斗路线收益不同。
4. 金币和经验能正确增减。
5. 奖励能改变下一场战斗。
6. 默认试玩模式下路线、奖励、商店至少有一次玩家输入。
7. 全自动批跑模式必须和玩家试玩模式明确区分。
