# G13 角色、世界观与内容圣经策划案

> 状态：v0.3 草案
> 依赖：G01、G03、G07、G08、G14
> 目的：补齐英雄、怪物家族、阵营、场景和叙事口径，让 Ouro Agent 有统一的暗黑终端辨识度。

---

## 1. 模块目标

角色与世界观模块负责回答：

1. 玩家为什么在终端里驱动一个英雄 Agent。
2. 英雄、敌人、装备和图鉴属于怎样的世界。
3. 不同角色如何在机制、Prompt 和视觉上区分。
4. 怪物家族和三档变体如何扩展。
5. 后续内容扩展如何保持统一风格。

---

## 2. 世界观一句话

在名为 Ouro Archive 的黑暗终端遗迹中，英雄不是肉身冒险者，而是被玩家唤醒的战斗代理。每一次副本都是一次从破碎日志、腐化图鉴和深层模型回声中重建自我的循环。

---

| 关键词 | 用法 |
|--------|------|

---

## 4. 叙事边界

必须做：

1. 每个英雄有职业、人格倾向、默认 Prompt 和命令行视觉标识。
2. 每个怪物家族有 I/II/III 三档设计方向。
3. 每个敌人有图鉴文本、机制暗示和阶段解锁信息。
4. 每件传奇装备有来源感和明确裁判边界。
5. 文案服务玩法，不写长篇小说。

不做：

1. MVP 不做大型剧情线。
2. 不做过多 NPC 对话。
3. 不用可爱、轻松、玩梗风格。
4. 不让世界观覆盖战斗可读性。

1. I 档名称要直观，适合教学。

## 9. 装备文案规则

| 档次 | 文案重点 |
|------|----------|
| 普通 | 先数值，再一句来源 |
| 英雄 | 先固定触发，再说明仪式来源 |
| 传奇 | 先 allowed_effects，再写传说，不允许文案暗示未实现效果 |

---

## 10. 文案规则

| 场景 | 文案要求 |
|------|----------|
| 战斗动作 | 1-2 行，先动作后结果 |
| 模型分析 | 简短，必须引用可见信息 |
| 图鉴 | 分阶段，越后越具体 |
| Build | 先策略，再标签，再数值 |
| 装备 | 先机制，后氛围 |
| 商店 | 暗黑交易感，但价格和效果清楚 |
| Session | 用 Echo / Ritual / Archive 叙事包装，但字段要可追踪 |

---

## 11. 验收标准

1. 至少 6 个英雄有 ID、中文名、职业、定位、默认 Prompt 方向。
2. 至少 8 个怪物家族有三档命名和机制方向。
3. 文案不影响战斗可读性。
4. 英雄设定能映射到技能、Prompt、Build 和 CLI 视觉。
5. 怪物设定能映射到图鉴、数值、掉落和敌人技能。
