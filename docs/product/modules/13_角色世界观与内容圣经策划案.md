# G13 角色、世界观与内容圣经策划案

> 状态：v0.2 草案  
> 依赖：G01、G03、G07、G08、G14  
> 目的：补齐角色、阵营、怪物、场景和叙事口径，让 Ouro Agent 不只是机制 demo，而是有辨识度的暗黑命令行游戏。

---

## 1. 模块目标

角色与世界观模块负责回答：

1. 玩家为什么在终端里驱动一个英雄 Agent。
2. 英雄、敌人、装备和图鉴属于怎样的世界。
3. 不同角色如何在机制、Prompt 和视觉上区分。
4. 后续内容扩展如何保持统一风格。

---

## 2. 世界观一句话

在名为 Ouro Archive 的黑暗终端遗迹中，英雄不是肉身冒险者，而是被玩家唤醒的战斗代理。每一次副本都是一次从破碎日志、腐化图鉴和深层模型回声中重建自我的循环。

关键词：

| 关键词 | 用法 |
|--------|------|
| Ouro | 循环、衔尾、无尽副本 |
| Archive | 图鉴、日志、记忆、trace |
| Black Candle | 商店、复活、污染交易 |
| Echo | 战斗回响、残响货币、死亡保留 |
| Corruption | 诅咒、污染 Prompt、暗影构筑 |

---

## 3. 叙事边界

必须做：

1. 每个英雄有职业、人格倾向、默认 Prompt 和命令行视觉标识。
2. 每个敌人有图鉴文本、机制暗示和阶段解锁信息。
3. 每件传奇装备有来源感和明确边界。
4. 文案服务玩法，不写长篇小说。

不做：

1. MVP 不做大型剧情线。
2. 不做过多 NPC 对话。
3. 不用可爱、轻松、玩梗风格。
4. 不让世界观覆盖战斗可读性。

## 4. MVP 英雄设定

### 4.1 暗影学徒

| 字段 | 内容 |
|------|------|
| ID | `hero_shadow_apprentice` |
| 中文名 | 阿斯缇娅 |
| 职业 | 暗影学徒 |
| 定位 | 法术、腐化、风险收益 |
| 默认倾向 | 优先处理高威胁后排，愿意用 MP 换节奏 |
| 视觉符号 | 兜帽、黑烛短杖、破碎光环 |
| 口吻 | 冷静、克制、像在读取战场日志 |
| 默认 Prompt 方向 | 先识别威胁和读条，再选择能阻止敌方关键行动的技能 |

命令行头像草案：

```text
   .^.
  /_#_\     ASTIA
 ( o o)     Shadow Apprentice
  /|!|\     hood + candle-staff
   / \      shadow / control / risk
```

战斗短标识：`[CNDL]`

### 4.2 灰烬守卫

| 字段 | 内容 |
|------|------|
| ID | `hero_ash_guardian` |
| 中文名 | 诺恩 |
| 职业 | 灰烬守卫 |
| 定位 | 防御、反击、稳定 |
| 默认倾向 | 优先保证生存，低血量时倾向防御或护盾 |
| 视觉符号 | 重甲、塔盾、灰烬裂纹 |
| 口吻 | 短句、稳健、判断直接 |
| 默认 Prompt 方向 | 维持 HP 安全线，不为短期伤害牺牲防线 |

命令行头像草案：

```text
  /###\     NORN
 | o o |    Ash Guardian
 |[###]|    tower shield
 /_| |_\    guard / shield / counter
```

战斗短标识：`[SHLD]`

### 4.3 裂弦猎手

| 字段 | 内容 |
|------|------|
| ID | `hero_broken_string_hunter` |
| 中文名 | 薇拉 |
| 职业 | 裂弦猎手 |
| 定位 | 高速、流血、补刀、打断 |
| 默认倾向 | 优先收割低血量敌人或打断即将行动的敌人 |
| 视觉符号 | 断弦弩、钩刃、前倾猎手姿态 |
| 口吻 | 简短、锐利、偏行动导向 |
| 默认 Prompt 方向 | 优先制造行动差和收割机会 |

命令行头像草案：

```text
  __/->     VELA
 /==\       Broken String Hunter
  \_\       crossbow + hook
  / \       bleed / speed / execute
```

战斗短标识：`[XBOW]`

MVP 第一轮 coding 可只实现暗影学徒，但数据结构必须能容纳 3 个英雄。

## 5. MVP 敌人与图鉴方向

| 敌人 | ID | 类型 | 机制 | 图鉴关键词 |
|------|----|------|------|------------|
| 饥饿信徒 | `enemy_hungry_cultist` | 普通怪 | 基础攻击，低血量更激进 | 信徒、饥饿、群体仪式 |
| 黑烛侍者 | `enemy_black_candle_acolyte` | 普通怪 | 读条较慢，但会施加腐化 | 黑烛、腐化、延迟威胁 |
| 档案吞噬者 | `enemy_archive_devourer` | Boss | 召唤、沉默、吞噬图鉴信息 | 档案、遗忘、Boss |

图鉴文本必须分阶段写，不要一次暴露完整机制。

---

## 6. 阵营与场景

| 阵营 / 场景 | 用途 |
|-------------|------|
| Black Candle 黑烛商会 | 商店、污染复活、交易代价 |
| Hollow Archive 空档案馆 | 图鉴、trace、记忆、Boss 场景 |
| Ash Gate 灰烬门 | 新手副本入口 |
| Corrupted Script 腐化脚本 | 诅咒、非法模型输出的叙事包装 |

---

## 7. 文案规则

| 场景 | 文案要求 |
|------|----------|
| 战斗动作 | 1-2 行，先动作后结果 |
| 模型分析 | 简短，必须引用可见信息 |
| 图鉴 | 分阶段，越后越具体 |
| 装备 | 先机制，后氛围 |
| 商店 | 暗黑交易感，但价格和效果清楚 |

---

## 8. 验收标准

1. 至少 3 个英雄有 ID、中文名、职业、定位、默认 Prompt 方向。
2. 至少 3 个敌人有图鉴分阶段方向。
3. 文案不影响战斗可读性。
4. 英雄设定能映射到技能、Prompt 和 CLI 视觉。
5. 内容数据可从本文件提炼到 G08 schema。
