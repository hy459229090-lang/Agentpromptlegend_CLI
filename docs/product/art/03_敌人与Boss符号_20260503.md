# Ouro Agent 敌人与 Boss 符号

> 版本：v0.2
> 日期：2026-05-03
> 目标：为怪物家族、三档敌人和 Boss 提供可读、可扩展的终端标识。

---

## 1. 通用规则

1. 敌人符号必须包含 tier 和 glyph，例如 `[II:k]`。
2. Boss 可以有更宽的符号，但不能超过战斗面板宽度。
3. ASCII-safe 是默认。
4. 图鉴和战斗中使用同一 family、tier、ID 与展示名。
5. no-color 模式下必须仍能判断危险等级。

## 3. 三档显示

```text
[I:c]   Hungry Cultist
[II:c]  Hunger Banneret
[III:C] Hunger Eucharist
```

规则：

1. I/II/III 必须前置。
2. III 档 Boss glyph 可以使用大写。
3. 列表中优先显示 tier、名称、HP、ATB、Codex 阶段。

---

## 4. 家族示例

### 4.1 黑烛家族

```text
[I:k]   Black Candle Acolyte
[II:k]  Black Candle Firekeeper
[III:K] Black Candle High Priest
```

小头像：

```text
  i
 /#\  Black Candle
 /_\
```

### 4.2 灰烬遗兵

```text
[I:g]   Ash Remnant
[II:g]  Ash Gate Warden
[III:G] Ash Gate Colossus
```

小头像：

```text
 [#]
 /|\  Ash Gate
 /_\
```

### 4.3 档案吞噬者

```text
[I:A]   Devouring Page
[II:A]  Archive Devourer
[III:A] Hollow Archivist
```

```text
==== HOLLOW ARCHIVIST [III:A] ====
     /\____/\
    /  [] [] \
   /___/\/\___\
      archive / devour / silence
```
