# Ouro Agent 敌人与 Boss 符号

> 版本：v0.4
> 日期：2026-05-04
> 目标：为怪物家族、三档敌人和 Boss 提供可读、可扩展的终端标识。

---

## 1. 通用规则

1. 敌人符号必须包含 tier 和 glyph，例如 `[II:k]`。
2. Boss 可以有更宽的符号，但不能超过战斗面板宽度。
3. ASCII-safe 是默认。
4. 图鉴和战斗中使用同一 family、tier、ID 与展示名。
5. no-color 模式下必须仍能判断危险等级。
6. 每个怪物家族至少定义 idle、attack、cast/charge、release、hit、death、codex reveal 动作状态。

## 3. 三档显示

```text
[I:c]   Hungry Cultist
[II:c]  Hunger Banneret
[III:C] Hunger Eucharist
```

规则：

1. I/II/III 必须前置。
2. III 档 Boss glyph 可以使用大写。
3. 列表中优先显示 tier、名称、HP、ATB、Codex 阶段。

## 6. 怪物动作状态

怪物不是静态列表项。每个家族至少有动作包：

| 动作 | 用途 | 示例 |
|------|------|------|
| idle | 战斗常态 | `c sways under hunger` |
| attack | 普攻 | `c claws at the candlelight` |
| cast / charge | 蓄力 | `k lowers the wick and begins a chant` |
| release | 蓄力释放 | `k releases a black syllable` |
| hit | 受击 | `k's flame buckles` |
| death | 死亡 | `c collapses into ash` |
| codex reveal | 图鉴解锁 | `A line writes itself into the Codex` |

黑烛家族示例：

```text
idle    : [I:k] candle low
charge  : [I:k] wick raised, chant forming
release : [I:k] black syllable released
hit     : [I:k] flame bends
death   : [I:k] candle out
codex   : [C] Black Candle chant pattern observed
```

## 7. 怪物战斗精灵包 v1

怪物不能只显示 `[II:k]` 和一行名字。战斗主屏必须显示怪物轮廓，并在蓄力、释放、受击、死亡时切换帧。

| 怪物 | 图标 | 精灵锚点 | 攻击效果 | 图鉴剪影 |
|------|------|----------|----------|----------|
| Black Candle Acolyte | `[I:c]` | 小烛芯、佝偻人形 | 黑烛抓击 | `(c)` |
| Black Candle Firekeeper | `[II:k]` | 烛台、长袍、烛芯 | 黑烛吟唱 | `(k)` |
| Mire Larva | `[I:m]` | 泥泡、短足 | 毒液喷吐 | `(m)` |
| Grave Gearling | `[II:g]` | 齿轮、坟钉腿 | 钉刺突进 | `[g]` |
| Hollow Indexer | `[III:B]` | 巨型索引书、缺页肢体 | 撕页审判 | `[INDEX]` |

```text
ACOLYTE idle       ACOLYTE break     ACOLYTE death
 (c)                (x)                 .
 /|\                /|\                /_\
 / \                / \                ash

FIREKEEPER idle    FIREKEEPER cast    FIREKEEPER hit
  (k)                (k)       <==      (k)
 /|w|\              /|w|\              /|w|!
  / \                / \                / \

GEARLING idle      GEARLING attack    GEARLING death
 [g]                [g]====>           [x]
 /|\                /|\                / \
 / \                / \                rust

INDEXER idle       INDEXER cast       INDEXER break
   [INDEX]            [INDEX]!!          [IND X]
  /|_||_|\           /|_||_|\           /|_||_|
   | || |             |/  \|             | xx |
  /__||__\           /__||__\           /__||__\
```

验收规则：

1. 普通怪至少 3 行，Boss 至少 5 行。
2. 敌人蓄力必须有 `telegraph` 帧，玩家能在画面上看出危险。
3. 被打断必须显示 `break`，不能只在日志写 interrupted。
4. 死亡帧必须和图鉴 reveal 关联，形成收藏反馈。
