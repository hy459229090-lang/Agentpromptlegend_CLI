# Ouro Agent 敌人与 Boss 符号

> 版本：v0.1  
> 日期：2026-05-03  
> 目标：为 MVP 敌人和 Boss 提供可读、可扩展的终端标识。

---

## 1. 通用规则

1. 敌人符号优先短小，适合列表显示。
2. Boss 可以有更宽的符号，但不能超过战斗面板宽度。
3. ASCII-safe 是默认。
4. 图鉴和战斗中使用同一 ID 与展示名。

---

## 2. 饥饿信徒

| 字段 | 内容 |
|------|------|
| ID | `enemy_hungry_cultist` |
| 类型 | 普通怪 |
| 标签 | cult / melee / frenzy |

列表符号：

```text
[c] Hungry Cultist
```

小头像：

```text
 /o\
 /|   Hungry Cultist
 / \
```
