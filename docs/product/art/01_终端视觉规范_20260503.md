# Ouro Agent 终端视觉规范

> 版本：v0.1  
> 日期：2026-05-03  
> 目标：保证终端界面美观、高性能、可读、可测试。

---

## 1. 视觉定位

Ouro Agent 的视觉不是华丽 UI，而是“黑暗档案终端”。玩家应该感觉自己在运行一套危险的战斗代理系统，而不是在看普通日志。

关键词：

| 关键词 | 含义 |
|--------|------|
| Archive | 档案、trace、图鉴 |
| Candle | 代价、商店、复活 |
| Echo | 模型调用、token、战斗回响 |
| Corruption | 诅咒、非法输出、状态异常 |

---

## 2. 层级规则

屏幕信息优先级：

1. 生死信息：HP、敌人 HP、Boss 技能、失败原因。
2. 行动信息：谁行动、目标是谁、技能是什么。
3. 结算信息：伤害、状态、冷却、MP。
4. 模型信息：Echo Cost、Ritual Time、Provider。
5. 氛围信息：角色台词、环境文案、装饰线。

氛围信息不能抢占前 4 层。

---

## 3. 颜色规范

| 用途 | ANSI | 无颜色替代 |
|------|------|------------|
| 标题 | bright white / yellow | 全大写标题 |
| 英雄 | yellow | `HERO:` |
| 敌人 | red | `ENEMY:` |
| Boss | bright red | `BOSS:` |
| 护盾 | cyan | `shield(n)` |
| 毒 / 腐化 | green / magenta | `poison(n)` / `corrupt(n)` |
| 奖励 | bright yellow | `REWARD:` |
| 警告 | bright red | `!` |
| Trace / 技术信息 | bright black | `trace:` |

必须支持 `--no-color`。

---

## 4. 字符模式

| 模式 | 默认 | 用途 |
|------|------|------|
| ASCII-safe | 是 | Windows PowerShell、CI、日志 |
| Unicode-enhanced | 否 | 现代终端，美观增强 |
| no-color | 可选 | 截图、兼容、测试 |

ASCII-safe 示例：

```text
HP [######----] 62/100
ATB [####------]
```

Unicode-enhanced 示例：

```text
HP ██████░░░░ 62/100
ATB ████░░░░░░
```

---

## 5. 性能规则

| 项 | 规则 |
|----|------|
| 常规刷新 | 4-8 FPS 上限 |
| 模型等待 | 1-2 FPS 上限 |
| 日志 | 主屏最多 5-8 行 |
| 动画 | 必须可关闭 |
| 测试 | 必须有 deterministic text snapshot |
| 高刷屏输出 | 禁止作为默认体验 |

---

## 6. Echo Cost 展示

底层保留真实字段，界面用游戏化文案。

| 技术字段 | 展示名 |
|----------|--------|
| `input_tokens` | Read Echo |
| `output_tokens` | Spoken Echo |
| `cached_tokens` | Sealed Echo |
| `total_tokens` | Echo Cost |
| `latency_ms` | Ritual Time |

展示示例：

```text
MODEL  provider=openai  model=gpt-5.4
Echo Cost: 1,284 tokens  Ritual Time: 1.7s  Trace: local
```

mock 模式：

```text
MODEL  provider=mock  model=mock-smart
Echo Cost: 0 tokens  Ritual Time: 12ms  Trace: local
```

---

## 7. 排版规则

1. 每屏最多 4 个主分区。
2. 数字与状态对齐优先。
3. 不使用超过 80-100 字符的关键行。
4. 敌人列表不超过 5 个可见敌人，更多敌人折叠。
5. 长日志进入 trace，不在主屏滚动刷屏。
