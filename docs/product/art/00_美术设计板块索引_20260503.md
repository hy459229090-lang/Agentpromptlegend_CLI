---

## 1. 板块目标

Ouro Agent 的美术不是传统图片资源，而是命令行中的视觉语言：

1. ASCII / Unicode 角色轮廓。
2. 终端面板布局。
3. ANSI 颜色和状态表现。
4. 暗黑风格文案。
5. Provider 配置、战斗、商店、地图等界面的一致性。

## 4. 风格限制

1. 默认 ASCII-safe，Unicode-enhanced 可选。
2. 不使用图片、字体、GUI 作为 MVP 依赖。
3. 不使用可爱化风格。
4. 不做大段装饰遮挡战斗信息。
5. 所有界面必须支持 `--no-color`。
