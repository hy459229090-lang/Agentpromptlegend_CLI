# Ouro Agent 英雄 Build 与怪物图鉴 UI 优化

> 版本：v0.1  
> 日期：2026-05-03  
> 用途：把英雄种类、Build、Buff/Debuff、怪物三档和 BattleLLMSession 转成可实现的终端 UI 规则。

---

## 1. 设计目标

1. 玩家选择英雄时能看懂“这个英雄怎么赢”。
2. 玩家查看 Build 时能看懂“装备和技能为什么搭配”。
3. 玩家看战斗时能看懂 Buff/Debuff 和怪物档次。
4. 玩家能看到模型 Session 成本，但不被 token 信息喧宾夺主。

---

## 2. 英雄列表最小信息

```text
[CNDL] ASTIA  Shadow Apprentice     Build: Black Candle Interrupt
       tags: shadow / control / risk     plan: interrupt chants

[SHLD] NORN   Ash Guardian          Build: Iron Bulwark
       tags: guard / shield / counter    plan: hold HP line
```

必须显示：

1. 战斗短标识。
2. 职业名。
3. Build 类型。
4. 3-4 个核心标签。
5. 一句策略计划。

---

## 3. Build 面板

```text
BUILD :: BLACK CANDLE INTERRUPT

Hero  : [CNDL] Astia / Shadow Apprentice
Gear  : Cracked Wand [common], Black Sun Codex [heroic]
Tags  : shadow(3), control(2), codex(1), risk(1)
Echo  : Corruption School active

Priority
1. Interrupt high-ATB casters.
2. Spend MP for tempo before enemy release.
3. Avoid attacking shielded targets unless no caster is active.
```

## 4. Buff / Debuff 面板

```text
BUFF
SHD shield(6)       absorbs next damage
FOC focus(1)        next skill gains power

DEBUFF
CRP corruption(2)   shadow effects are stronger
STG stagger(1)      ATB delayed
OMN omen(2)         delayed penalty if ignored
```

## 7. 验收标准

1. 英雄列表能展示 Build 类型。
2. 战斗主屏能展示 Buff/Debuff 分组。
3. 怪物能展示 tier + glyph + codex stage。
4. Session 面板能展示 battle/session/token 信息。
5. no-color 模式下仍然可读。
