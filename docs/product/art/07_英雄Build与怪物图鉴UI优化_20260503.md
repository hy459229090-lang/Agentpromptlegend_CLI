# Ouro Agent 英雄 Build 与怪物图鉴 UI 优化

> 版本：v0.3
> 日期：2026-05-04
> 用途：把英雄种类、Build、Buff/Debuff、怪物三档和 BattleLLMSession 转成可实现的终端 UI 规则。

---

## 1. 设计目标

1. 玩家选择英雄时能看懂“这个英雄怎么赢”。
2. 玩家查看 Build 时能看懂“装备和技能为什么搭配”。
3. 玩家看战斗时能看懂 Buff/Debuff 和怪物档次。
4. 玩家能看到模型 Session 成本，但不被 token 信息喧宾夺主。
5. 玩家能看到 Build 快成型、已成型、胡牌和下一步该拿什么。
6. 玩家能把图鉴当成卡片收藏，而不是文字列表。

---

## 2. 英雄列表最小信息

```text
[CNDL] ASTIA  Shadow Apprentice     Build: Black Candle Interrupt
       tags: shadow / control / risk     plan: interrupt chants

[SHLD] NORN   Ash Guardian          Build: Iron Bulwark
       tags: guard / shield / counter    plan: hold HP line
```

必须显示：

1. 战斗短标识。
2. 职业名。
3. Build 类型。
4. 3-4 个核心标签。
5. 一句策略计划。

## 7. 验收标准

1. 英雄列表能展示 Build 类型。
2. 战斗主屏能展示 Buff/Debuff 分组。
3. 怪物能展示 tier + glyph + codex stage。
4. Session 面板能展示 battle/session/token 信息。
5. no-color 模式下仍然可读。
6. Build 面板能展示 active / near / best next picks。
7. 图鉴详情必须卡片化，并显示 locked/fog/unlocked 状态。
8. Context 窗口必须显示 Strategy/Codex/Memory/Prompt edit 槽位。

---

## 9. 武器与 Build 图标语法

武器、技能和 Build 不能只显示名称。它们必须有短图标、轮廓和玩法标签，让玩家在战斗中能一眼识别当前组合。

| 类型 | 图标 | 轮廓 | 典型 Build |
|------|------|------|------------|
| Staff | `[W:STF]` | `c==*` | shadow / control / cast |
| Shield | `[W:SHD]` | `[#]` | guard / shield / counter |
| Crossbow | `[W:XBW]` | `==>` | bleed / execute / speed |
| Vial | `[W:VIL]` | `(v)` | poison / attrition |
| Gear | `[W:GER]` | `[o]` | construct / trap |
| Bell | `[W:BEL]` | `)o(` | echo / cleanse / support |
| Blade | `[W:BLD]` | `/==` | bleed / risk |
| Codex | `[W:CDX]` | `[::]` | control / codex |

Build 阶段徽章：

| 阶段 | 徽章 | 展示规则 |
|------|------|----------|
| Seed | `[SEED]` | 拿到第一个核心标签后显示 |
| Pair | `[PAIR]` | 核心标签达到 2 点后显示 |
| Online | `[ONLINE]` | 首个羁绊可触发后显示 |
| High Roll | `[HIGH]` | 核心武器 + 2 词条 + 羁绊后显示 |
| Locked In | `[LOCK]` | 两个羁绊或关键传奇成型后显示 |

战斗 HUD 示例：

```text
[W:XBW] ==>  Severed String
[B:EXE] BLEED EXECUTION      [PAIR]
bleed [##-] 2/3  execute [#--] 1/3  speed [#--] 1/3
NEXT: bleed affix / hunter relic / execute skill
```

验收规则：

1. 英雄详情、奖励选择、战斗主屏和战报必须使用同一套武器图标。
2. Build 阶段变化必须出现在战斗画面和奖励选择画面。
3. 没有颜色时仍能通过 `[W:*]`、`[B:*]`、阶段徽章判断当前组合。
