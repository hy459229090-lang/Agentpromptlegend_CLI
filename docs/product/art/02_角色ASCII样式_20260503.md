# Ouro Agent 角色 ASCII 样式

> 版本：v0.5
> 日期：2026-05-04
> 目标：为 MVP+ 六个英雄提供更有职业辨识度、可落地到命令行的角色样式。
> 本版新增：补齐战斗精灵包要求，角色不再只有头像和短标识。

---

## 1. 样式规则

1. 每个头像必须有 ASCII-safe 版本。
2. Unicode-enhanced 只作为可选增强。
3. 头像宽度建议不超过 18 字符，战斗面板中可压缩成 4-6 字符短标识。
4. 头像不能影响 HP/MP/ATB 的阅读。
5. 英雄展示名、职业名、战斗短标识必须紧邻头像。
6. 每个英雄必须有一个可识别主道具：烛杖、塔盾、弩机、毒瓶、齿轮、断铃。
7. 每个英雄必须有立绘、Idle、Cast、Attack、Hit、Guard、Low HP、Victory、Defeat 资产状态。

---

## 2. 职业识别规则

| 识别层 | 说明 | 示例 |
|--------|------|------|
| 主剪影 | 玩家先看到角色大轮廓 | 兜帽、重盾、弩臂 |
| 主道具 | 让职业一眼成立 | 烛杖、塔盾、断弦弩、毒瓶、齿轮、断铃 |
| 战斗短标识 | 低空间 UI 使用 | `[CNDL]`、`[SHLD]`、`[XBOW]`、`[VENM]`、`[GEAR]`、`[ECHO]` |
| 行为提示 | 和玩法绑定 | 打断、护卫、收割 |

## 3. 暗影学徒 Astia

| 字段 | 内容 |
|------|------|
| ID | `hero_shadow_apprentice` |
| 中文名 | 阿斯缇娅 |
| 英文名 | Astia |
| 职业 | Shadow Apprentice |
| 视觉定位 | 兜帽法师 + 黑烛短杖 |
| 标签 | shadow / control / risk |
| 战斗短标识 | `[CNDL]` |
| 一眼识别 | 兜帽、烛杖、施法姿态 |

ASCII-safe：

```text
   .^.
  /_#_\     ASTIA
 ( o o)     Shadow Apprentice
  /|!|\     hood + candle-staff
   / \      shadow / control / risk
```

Unicode-enhanced：

```text
   .^.
  /_▓_\     ASTIA
 ( • •)     Shadow Apprentice
  /│✦│\     hood + black candle
   ╱ ╲      shadow / control / risk
```

战斗短称：

```text
[CNDL] ASTIA :: Shadow Apprentice :: interrupt / hex / risk
```

角色选择短卡：

```text
[1] ASTIA  [CNDL]  Shadow Apprentice
    hooded caster with a black-candle staff
    role: interrupt enemy chants, trade MP for tempo
```

动作状态：

```text
idle :  .^.   candle low
cast :  .^.   candle raised
hit  :  .^.   flame bends back
guard:  .^.   cloak closes
low  :  .^.   candle guttering
win  :  .^.   black flame steady
dead :  ._.   candle out
```

## 10. 落地要求

1. 英雄列表默认使用“短卡”，战斗主屏默认使用“战斗短标识”。
2. 完整头像只在英雄详情页、选择页或结算页展示。
3. 如果终端宽度不足，优先保留战斗短标识和职业名。
4. 快照测试必须覆盖 ASCII-safe 模式。
5. 英雄详情必须显示 Build 类型、核心标签和当前羁绊。
6. 战斗动作帧必须使用对应英雄的动作状态，不允许所有英雄共用同一动作文案。

---

## 11. 战斗精灵包 v1

英雄在战斗主屏中不能只显示 `[CNDL] ASTIA` 这类短标识。每个英雄必须提供 4-6 行战斗精灵，并在行动中切换帧。

| 英雄 | 武器图标 | Build 图标 | 精灵锚点 | 主要动作辨识 |
|------|----------|------------|----------|--------------|
| Astia | `[W:STF] c==*` | `[B:HEX]` | 兜帽、烛杖、黑烛火 | 烛火前伸、封印弹道 |
| Norn | `[W:SHD] [#]` | `[B:BLK]` | 塔盾、正面站姿 | 盾前压、格挡反击 |
| Vela | `[W:XBW] ==>` | `[B:EXE]` | 横弩、断弦、前倾 | 拉弦、箭矢弹道 |
| Mirel | `[W:VIL] (v)` | `[B:PSN]` | 遮眼纱、毒瓶 | 倾瓶、毒雾扩散 |
| Korr | `[W:GER] [o]` | `[B:TRP]` | 齿轮背箱、坟钉 | 插钉、机关展开 |
| Sera | `[W:BEL] )o(` | `[B:ECH]` | 断铃、封喉、空谱 | 铃波、净化回声 |

### 11.1 压缩战斗帧

```text
ASTIA idle        ASTIA cast        ASTIA hit
  .^.              .^.                .x.
 /|c|\            /|c|==*            /|c
  / \              / \                /\

NORN idle         NORN guard        NORN impact
  O                O                  O      <==#
 /#\              [#]                /#\
 / \              / \                / \

VELA idle         VELA windup       VELA impact
  o                o                  o        ===>
 /|\              /|\                /|
 /->              /==>               / \

MIREL idle        MIREL cast        MIREL impact
 .o.              .o.                .o.      ~~~>
 /(v)\            /(v)==            /|\
 / \              / \                / \

KORR idle         KORR trap         KORR impact
 [o]              [o]                [o]      x==#
 /|#|\            /|#|==            /|#|
 /T\              /T\                /T\

SERA idle         SERA cast         SERA cleanse
 .o.              .o.                .o.      )))
 /)o(\            /)o(==            /|\
 / \              / \                / \
```

### 11.2 使用规则

1. 英雄选择页可以用立绘，战斗主屏必须用压缩精灵。
2. 普攻、技能、受击、格挡至少切换 1 个不同帧。
3. 每个英雄的武器图标必须出现在英雄 HUD 或 Build HUD。
4. 同一动作类型不能让所有英雄共用同一精灵或同一文案。
