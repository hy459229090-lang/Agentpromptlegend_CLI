# Ouro Agent 角色 ASCII 样式

> 版本：v0.1  
> 日期：2026-05-03  
> 目标：为 MVP 三个英雄提供命令行可读的角色样式。

---

## 1. 样式规则

1. 每个头像必须有 ASCII-safe 版本。
2. Unicode-enhanced 只作为可选增强。
3. 头像宽度建议不超过 18 字符。
4. 头像不能影响 HP/MP/ATB 的阅读。
5. 英雄展示名和标签必须紧邻头像。

---

## 2. 暗影学徒 Astia

| 字段 | 内容 |
|------|------|
| ID | `hero_shadow_apprentice` |
| 中文名 | 阿斯缇娅 |
| 英文名 | Astia |
| 职业 | Shadow Apprentice |
| 标签 | shadow / control / risk |

ASCII-safe：

```text
  /\
 /##\   ASTIA
 |[]|   Shadow Apprentice
 /||\   shadow / control / risk
```

Unicode-enhanced：

```text
  /\
 /▓▓\   ASTIA
 |[]|   Shadow Apprentice
 /╫╫\   shadow / control / risk
```

战斗短称：

```text
ASTIA :: Shadow Apprentice
```
