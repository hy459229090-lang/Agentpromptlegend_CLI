# Ouro Agent 角色 ASCII 样式

> 版本：v0.2  
> 日期：2026-05-03  
> 目标：为 MVP 三个英雄提供更有职业辨识度、可落地到命令行的角色样式。  
> 本版修正：v0.1 的头像过于抽象，玩家很难从图形本身看出职业。

---

## 1. 样式规则

1. 每个头像必须有 ASCII-safe 版本。
2. Unicode-enhanced 只作为可选增强。
3. 头像宽度建议不超过 18 字符，战斗面板中可压缩成 4-6 字符短标识。
4. 头像不能影响 HP/MP/ATB 的阅读。
5. 英雄展示名、职业名、战斗短标识必须紧邻头像。
6. 每个英雄必须有一个可识别主道具：烛杖、塔盾、弩机。

---

## 2. 职业识别规则

| 识别层 | 说明 | 示例 |
|--------|------|------|
| 主剪影 | 玩家先看到角色大轮廓 | 兜帽、重盾、弩臂 |
| 主道具 | 让职业一眼成立 | 烛杖、塔盾、断弦弩 |
| 战斗短标识 | 低空间 UI 使用 | `[CNDL]`、`[SHLD]`、`[XBOW]` |
| 行为提示 | 和玩法绑定 | 打断、护卫、收割 |

## 3. 暗影学徒 Astia

| 字段 | 内容 |
|------|------|
| ID | `hero_shadow_apprentice` |
| 中文名 | 阿斯缇娅 |
| 英文名 | Astia |
| 职业 | Shadow Apprentice |
| 视觉定位 | 兜帽法师 + 黑烛短杖 |
| 标签 | shadow / control / risk |
| 战斗短标识 | `[CNDL]` |
| 一眼识别 | 兜帽、烛杖、施法姿态 |

ASCII-safe：

```text
   .^.
  /_#_\     ASTIA
 ( o o)     Shadow Apprentice
  /|!|\     hood + candle-staff
   / \      shadow / control / risk
```

Unicode-enhanced：

```text
   .^.
  /_▓_\     ASTIA
 ( • •)     Shadow Apprentice
  /│✦│\     hood + black candle
   ╱ ╲      shadow / control / risk
```

战斗短称：

```text
[CNDL] ASTIA :: Shadow Apprentice :: interrupt / hex / risk
```

角色选择短卡：

```text
[1] ASTIA  [CNDL]  Shadow Apprentice
    hooded caster with a black-candle staff
    role: interrupt enemy chants, trade MP for tempo
```

## 4. 灰烬守卫 Norn

| 字段 | 内容 |
|------|------|
| ID | `hero_ash_guardian` |
| 中文名 | 诺恩 |
| 英文名 | Norn |
| 职业 | Ash Guardian |
| 视觉定位 | 重甲守卫 + 塔盾 |
| 标签 | guard / shield / counter |
| 战斗短标识 | `[SHLD]` |
| 一眼识别 | 宽肩、盾面、正面站姿 |

ASCII-safe：

```text
  /###\     NORN
 | o o |    Ash Guardian
 |[###]|    tower shield
 /_| |_\    guard / shield / counter
```

Unicode-enhanced：

```text
  /███\     NORN
 | • • |    Ash Guardian
 |[▣▣▣]|    tower shield
 /_| |_\    guard / shield / counter
```

战斗短称：

```text
[SHLD] NORN :: Ash Guardian :: guard / absorb / counter
```

角色选择短卡：

```text
[2] NORN   [SHLD]  Ash Guardian
    armored frontliner behind a cracked tower shield
    role: keep HP above safety line, punish reckless enemies
```

## 5. 裂弦猎手 Vela

| 字段 | 内容 |
|------|------|
| ID | `hero_broken_string_hunter` |
| 中文名 | 薇拉 |
| 英文名 | Vela |
| 职业 | Broken String Hunter |
| 视觉定位 | 断弦弩手 + 钩刃 |
| 标签 | bleed / speed / execute |
| 战斗短标识 | `[XBOW]` |
| 一眼识别 | 横向弩臂、前倾姿态、钩刃线条 |

ASCII-safe：

```text
  __/->     VELA

```

Unicode-enhanced：

```text
  ━━/➜     VELA
 /══\      Broken String Hunter
  ╲_╲      crossbow + hook
  ╱ ╲      bleed / speed / execute
```

战斗短称：

```text
[XBOW] VELA :: Broken String Hunter :: bleed / interrupt / execute
```

角色选择短卡：

```text
[3] VELA   [XBOW]  Broken String Hunter
    crossbow hunter with a snapped string and hook blade
    role: create action gaps, finish low-HP enemies
```

## 7. 落地要求

1. 英雄列表默认使用“短卡”，战斗主屏默认使用“战斗短标识”。
2. 完整头像只在英雄详情页、选择页或结算页展示。
3. 如果终端宽度不足，优先保留 `[CNDL]`、`[SHLD]`、`[XBOW]` 和职业名。
4. 快照测试必须覆盖 ASCII-safe 模式。
