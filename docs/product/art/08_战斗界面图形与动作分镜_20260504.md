# Ouro Agent 战斗界面图形与动作分镜

> 版本：v0.1
> 日期：2026-05-04
> 用途：把战斗界面从“文字日志”升级为“CLI 图形化对战场景”的可实现规格。

---

## 1. 结论

战斗主屏必须是图形化对战界面，不允许只有单位列表、逐行日志或最终报告。

最低可接受版本也必须同时具备：

1. 左侧英雄、右侧怪物的对战站位。
2. 场景背景层。
3. 英雄和怪物的 4-6 行战斗精灵。
4. 中央技能弹道/命中/格挡效果层。
5. HP/MP/ATB/状态 HUD。
6. Build 胡牌进度和当前武器/技能图标。
7. 下方短日志，只解释结果，不替代画面。

---

## 2. 屏幕层级

| 层 | 名称 | 内容 | 规则 |
|----|------|------|------|
| L0 | Scene | 地牢名、背景符号、天气/烛火/门框 | 低密度，不挡 HUD |
| L1 | Actor | 英雄精灵、怪物精灵、站位 | 左英雄右怪物 |
| L2 | Effect | 弹道、斩击、护盾、毒雾、命中数字 | 只在行动帧出现 |
| L3 | HUD | HP/MP/ATB、Buff/Debuff、目标 | 固定位置 |
| L4 | Build | 武器、Build 阶段、差几张胡 | 靠近英雄侧 |
| L5 | Log | 最近 3-5 条短日志 | 不能刷屏 |

## 3. 强制左右对战版式

### 3.1 100 列以上默认布局

```text
OURO AGENT :: EMBER CRYPT :: FLOOR 2                         AUTO WATCH
.. candles .. broken arch .. ash line ..                     echo be_017

+---------------- HERO ----------------+      +-------------- ENEMY --------------+
| [CNDL] ASTIA                         |      | [II:k] BLACK CANDLE FIREKEEPER    |
|      .^.                             |      |          (k)                       |
|     /|c|\    -- shadow seal -->      |      |         /|w|\     chanting         |
|      / \                             |      |          / \                       |
| HP [########--] 82/100  MP [####--]  |      | HP [#####-----] 31/60  ATB [###--] |
| ATB [#######---]  BUFF: ward(2)      |      | DEBUFF: sealed(1)  CHARGE: 43%     |
+--------------------------------------+      +-----------------------------------+

WEAPON [W:STF] Black Candle Staff        BUILD [ONLINE] shadow 3/3 control 2/3
NEXT PICK: control affix / silence relic       NEED: control +1 for HIGH ROLL

ACTION STRIP  idle -> cast_windup -> projectile -> impact -> judge
LOG
> Astia casts Wick-Seal at Firekeeper.
> Seal lands: charge interrupted, shadow +8.
```

验收规则：

1. 英雄和怪物必须左右分栏，不能上下列表化。
2. 技能效果必须穿过中间区域，例如 `-->`、`==>`、`~~~`、`***`。
3. 日志只能作为补充，不得成为主画面。
4. 关闭动画时仍显示 `ACTION STRIP` 的当前 turn frame。

### 3.2 80 列压缩布局

```text
EMBER CRYPT F2                                      AUTO

[CNDL] ASTIA                         [II:k] FIREKEEPER
   .^.                                      (k)
  /|c|\  -- seal -->                       /|w|\
   / \                                      / \
HP ########-- 82/100                 HP #####----- 31/60
MP ####--     ATB #######---         ATB ###--  charge 43%

[W:STF] Staff   BUILD ONLINE shadow 3/3 control 2/3
LOG: Wick-Seal interrupts chant. shadow +8.
```

## 4. 战斗精灵规格

### 4.1 尺寸

| 对象 | 默认尺寸 | 压缩尺寸 | 说明 |
|------|----------|----------|------|
| 英雄 | 9-13 字宽，4-6 行 | 5-8 字宽，3 行 | 左侧固定 |
| 普通怪 | 7-11 字宽，3-5 行 | 5-8 字宽，3 行 | 右侧固定 |
| Boss | 15-24 字宽，5-7 行 | 11-16 字宽，4 行 | 占右侧整栏 |
| 弹道 | 8-24 字宽，1 行 | 5-12 字宽，1 行 | 位于中线 |

### 4.2 英雄动作包

每个英雄至少交付这些帧，不能只写动作短句：

| 帧 | 用途 | 必须变化 |
|----|------|----------|
| idle | 常态 | 职业主道具可见 |
| ready | ATB 将满 | 姿态前压或武器抬起 |
| attack_windup | 普攻前摇 | 武器方向变化 |
| attack_impact | 普攻命中 | 中线出现斩击/箭/钉 |
| cast_windup | 技能前摇 | 法器/瓶/铃/齿轮变化 |
| cast_release | 技能释放 | 中线出现技能符号 |
| guard | 防御/护盾 | 护盾或格挡姿态 |
| hit | 受击 | 姿态后仰或闪烁 |
| low_hp | 低血 | 轮廓破损或主道具变暗 |
| victory | 胜利 | 姿态抬起 |
| defeat | 战败 | 倒地或失去主道具 |

### 4.3 怪物动作包

| 帧 | 用途 | 必须变化 |
|----|------|----------|
| idle | 常态 | 家族特征可见 |
| telegraph | 敌方蓄力 | 右侧出现 charge 或 warning |
| attack_windup | 攻击前摇 | 爪、烛芯、针、书页等抬起 |
| attack_impact | 攻击命中 | 中线向左移动 |
| cast_release | 释放技能 | 符号/火/毒/页片出现 |
| hit | 受击 | 轮廓破损 |
| break | 被打断/破防 | charge 消失或 glyph 破裂 |
| death | 死亡 | 缩成残骸或灰 |
| codex_reveal | 图鉴解锁 | 残骸变卡片剪影 |

## 5. 英雄战斗精灵示例

### 5.1 Astia / Shadow Apprentice

```text
idle
  .^.
 /|c|\
  / \

cast_windup
  .^.
 /|c|==*
  / \

cast_release
  .^.        --*==>
 /| |\
  / \

hit
  .x.
 /|c
  /\
```

视觉锚点：兜帽、烛杖、黑烛火。
武器图标：`[W:STF] c==*`。
Build 图标：`[B:HEX] shadow/control`。

### 5.2 Norn / Ash Guardian

```text
idle
  O
 /#\
 / \

guard
  O
 [#]
 / \

attack_impact
  O      <==#
 /#\
 / \

hit
  o
 /#\!
 / \
```

视觉锚点：塔盾、正面站姿、灰烬边。
武器图标：`[W:SHD] [#]`。
Build 图标：`[B:BLK] guard/shield/counter`。

### 5.3 Vela / Broken String Hunter

```text
idle
  o
 /|\
 /->

attack_windup
  o
 /|\
 /==>

attack_impact
  o        ===>
 /|
 / \

victory
  o/
 /|
 /->
```

视觉锚点：横弩、前倾、断弦。
武器图标：`[W:XBW] ==>`。
Build 图标：`[B:EXE] bleed/execute/speed`。

## 7. 动作时间轴

| 阶段 | 时长建议 | 屏幕变化 |
|------|----------|----------|
| select | 0.2s | 高亮行动者边框 |
| windup | 0.3s | 行动者切到前摇帧 |
| travel | 0.2s | 中线出现弹道/斩击/毒雾 |
| impact | 0.3s | 目标切到 hit/break/guard 帧 |
| judge | 0.2s | 飘出伤害、打断、治疗、护盾数字 |
| recover | 0.2s | 回到 idle/low_hp/death |

`--no-animation` 模式下跳过等待，但必须输出 select、impact、judge 三帧的最终快照。

## 8. 武器、Build 与 Icon 语法

### 8.1 武器图标

| 类型 | ASCII | Unicode 增强 | 绑定玩法 |
|------|-------|--------------|----------|
| Staff | `[W:STF] c==*` | staff + flame | shadow/control/cast |
| Shield | `[W:SHD] [#]` | shield block | guard/counter |
| Crossbow | `[W:XBW] ==>` | bolt | bleed/execute |
| Vial | `[W:VIL] (v)` | vial drop | poison/attrition |
| Gear | `[W:GER] [o]` | gear | construct/trap |
| Bell | `[W:BEL] )o(` | bell wave | echo/cleanse |
| Blade | `[W:BLD] /==` | blade slash | bleed/risk |
| Codex | `[W:CDX] [::]` | book | control/codex |

### 8.2 Build 徽章

| 阶段 | 徽章 | 画面反馈 |
|------|------|----------|
| Seed | `[SEED]` | Build 行出现 1 个核心图标 |
| Pair | `[PAIR]` | 中线效果多 1 个短特效 |
| Online | `[ONLINE]` | Build 栏高亮，行动帧出现 resonance |
| High Roll | `[HIGH]` | 背景出现 1 帧强化，奖励卡标星 |
| Locked In | `[LOCK]` | 结算页出现完整 Build 卡 |

### 8.3 Build HUD 示例

```text
[W:STF] c==*  Black Candle Staff
[B:HEX] BLACK CANDLE INTERRUPT       [ONLINE]
shadow  [###] 3/3   control [##-] 2/3   risk [#--] 1/3
NEXT: control affix / silence relic / wick codex
```

---

## 9. 不通过条件

1. 战斗画面是单列文本日志。
2. 英雄和怪物没有左右对战关系。
3. 角色/怪物只有名字、头像或一句动作文案，没有精灵帧。
4. 技能没有中线弹道/命中/格挡层。
5. 武器和 Build 只显示名称，不显示图标、标签和阶段。
6. 图形元素遮挡 HP/MP/ATB。
7. `--no-color` 后无法识别危险、动作或 Build 阶段。
