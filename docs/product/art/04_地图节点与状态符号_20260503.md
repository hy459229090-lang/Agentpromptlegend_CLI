# Ouro Agent 地图节点与状态符号

> 版本：v0.1  
> 日期：2026-05-03  
> 目标：统一路线地图、节点、状态和资源符号。

---

## 1. 地图节点符号

| 节点 | node type | ASCII | Unicode | 说明 |
|------|-----------|-------|---------|------|
| 普通怪 | `normal_combat` | `[M]` | `⚔` | 基础战斗 |
| 精英怪 | `elite_combat` | `[E]` | `◆` | 高风险战斗 |
| 宝箱怪 | `mimic_chest` | `[?]` | `▣` | 战斗奖励节点 |
| 商店 | `shop` | `[$]` | `¤` | 安全运营节点 |
| 事件 | `event` | `[*]` | `✦` | 随机选择 |
| Boss | `boss` | `[B]` | `☠` | 阶段终点 |

ASCII 地图示例：

```text
FLOOR 2

        [E]
       /
[M] - [?] - [$]
       \
        [M]
```

## 2. 状态符号

| 状态 | status | ASCII | Unicode | 显示 |
|------|--------|-------|---------|------|
| 中毒 | `status_poison` | `PSN` | `☠` | `poison(2)` |
| 流血 | `status_bleed` | `BLD` | `✚` | `bleed(1)` |
| 护盾 | `status_shield` | `SHD` | `⬡` | `shield(6)` |
| 腐化 | `status_corruption` | `CRP` | `◈` | `corrupt(1)` |
| 沉默 | `status_silence` | `SLN` | `…` | `silence(1)` |

主屏默认用完整英文短词，不只用符号，避免玩家看不懂。

## 4. 风险等级

| 风险 | ASCII | 用途 |
|------|-------|------|
| low | `risk: low` | 普通怪、商店 |
| medium | `risk: med` | 宝箱怪、事件 |
| high | `risk: high` | 精英怪、Boss |

不要只用颜色表达风险，no-color 模式必须可读。
