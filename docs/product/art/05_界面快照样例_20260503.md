> 版本：v0.2  
> 日期：2026-05-03

---

## 1. 主菜单

```text
OURO AGENT :: PROMPT LEGEND

[1] New Run
[2] Configure Model
[3] Codex / Archive
[4] Quit

Status: provider=mock  model=mock-smart  visual=ascii
```

## 2. Provider 配置

```text
MODEL PROVIDER

[1] mock                  no API key required
[2] openai                env: OPENAI_API_KEY
[3] anthropic             env: ANTHROPIC_API_KEY
[4] openai-compatible     env + base_url required

Current
provider : mock
model    : mock-smart
base_url : -

```
