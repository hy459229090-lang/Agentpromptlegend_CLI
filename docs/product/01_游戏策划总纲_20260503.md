# Ouro Agent 游戏策划总纲

> 版本：v0.1  
> 日期：2026-05-03  
> 暂定名：Ouro Agent: Prompt Legend  
> 文档定位：从游戏策划角度定义这是什么游戏、好玩在哪里、第一版不能跑偏到哪里。

---

## 1. 游戏定位

Ouro Agent 是一款严肃暗黑风格的命令行 AI 肉鸽。玩家不直接操作战斗，而是在战斗外构筑一个英雄 Agent：选择英雄、装备、技能、词条、Build 和英雄 Prompt。战斗开始后，英雄由模型按读条节奏自动决策，玩家通过命令行观战。

一句话体验：

> 我不是在战斗中点技能，而是在训练一个会自己下副本的黑暗英雄。

---

## 2. 目标玩家

| 玩家 | 需求 |
|------|------|
| 命令行用户 | 想在终端里玩一个有深度、有反馈的摸鱼游戏 |
| AI / Prompt 用户 | 想看到自己的 Prompt 如何影响战斗决策 |
| 肉鸽玩家 | 想要路线选择、Build 成型、风险收益和失败重开 |
| 模型玩家 | 想比较不同模型在同一构筑下的表现 |

第一版优先服务前两类玩家，但不能牺牲肉鸽游戏性。

---

## 3. 核心乐趣

| 乐趣   | 设计落点                        |
| ---- | --------------------------- |
| 构筑乐趣 | 英雄、装备、词条、技能、Prompt、羁绊共同形成打法 |
| 观战乐趣 | 战斗中看到英雄判断、行动、失误、爆发和翻盘       |
| 运营乐趣 | 选路线、进商店、拿奖励、牺牲收益换安全         |
| 调教乐趣 | 玩家 Prompt 会改变英雄的优先级和风险偏好    |
| 发现乐趣 | 图鉴逐步揭示怪物机制，模型可利用已解锁信息       |

---

## 4. 游戏边界

必须做：

1. 单英雄构筑。
2. 战斗外玩家运营。
3. 战斗中 AI 自动行动。
4. 本地确定性结算。
5. 命令行观战反馈。
6. 失败后保留图鉴等长期进度。

第一版不做：

1. 小队系统。
2. 玩家战斗中手动选技能。
3. 在线排行榜。
4. 玩家对战。
5. 大型剧情。
6. 敌人也调用模型。

---

## 5. MVP 体验目标

MVP 不追求内容多，追求闭环清楚。

| 目标 | 标准 |
|------|------|
| 可进入一局 | 玩家能选英雄并进入新手副本 |
| 可自动战斗 | 英雄能由 mock model 或真实模型自动行动 |
| 可看懂战斗 | 玩家知道英雄做了什么、为什么、造成什么后果 |
| 可做选择 | 关卡间能选路线、拿奖励、买装备、改 Prompt |
| 可失败 | 死亡是合理结果，并有本局外保留 |
| 可验证 | 不用 API key 也能跑 mock demo |

## 6. 第一版体验样例

```text
[路线选择]
左：普通怪 - 饥饿信徒
右：商店 - 黑烛商人

你选择普通怪，获得经验和掉落机会。

[战斗]
阿斯缇娅 ATB 满。
她审视战场：后排信徒读条即将完成。
模型选择：cast_skill / skill_shadow_sting / enemy_cultist_02
裁判结算：造成 27 暗影伤害，附加 腐化 1 层。

[战后]
获得 18 金币，12 经验。
奖励三选一：
1. 裂骨匕首
2. 腐化词条
3. 观察者残页
```

---

## 7. 成功标准

第一版成功不是“模型多聪明”，而是：

1. 玩家愿意看战斗过程。
2. 玩家能感觉自己的构筑影响了英雄行为。
3. AI 失误被包装成游戏风险，而不是程序崩溃。
4. 每局有路线和奖励选择，不只是连续战斗。
5. 后续 coding 工具能从策划案直接拆任务。
