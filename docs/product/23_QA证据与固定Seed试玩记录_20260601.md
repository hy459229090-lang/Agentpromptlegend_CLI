1. 自动化测试：`tests/unit/...` 或 `tests/integration/...`。
2. 固定 seed 命令输出：`venv312/bin/ouro ... --seed ...`。
3. trace 或示例输出：`*.trace.jsonl`、`examples/`、命令日志。
4. 视觉/宽度验收：80/100/120 列、英文/中文、`visual_width(line) <= width`。
5. 人工试玩记录：包含日期、命令、seed、语言、观察结果和结论。

不得把 `done` 需求的证据写成 `TBD`、`待补`、`UI 快照` 这类不可复验占位。
