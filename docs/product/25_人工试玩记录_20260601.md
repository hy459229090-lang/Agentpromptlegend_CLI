## 2. 观察重点

1. 新手完整 run 是否能在不读源码、不联网、不提供 API key 的情况下推进。
2. 路线、奖励、商店、休息是否给出风险、收益、Build 适配和决策理由。
3. 战斗是否保留 turn-by-turn frame，且 `--no-animation` 不删除战斗信息。
4. Boss 战是否显示楼层、Boss charge、phase、chant release、HIGH ROLL 等大事件。
5. 失败是否能解释资源、目标、Build 和下一局建议。
6. 结束后是否写入 Run Archive 与 Death History，且不包含明文 API key。
