## 2. 当前必须先策划清楚的模块

第一批必须清楚，否则 coding 工具会跑偏：

1. 核心循环：玩家在哪里操作，哪里不能操作。
2. 战斗系统：AI 行动和本地结算边界。
3. 英雄构筑：装备、词条、Prompt 和羁绊如何影响战斗。
4. 关卡路线：普通怪、宝箱怪、商店、Boss 的风险收益。
5. 模型行动：输入输出 schema、非法行动、降级。
6. CLI 表现：玩家为什么愿意看自动战斗。
7. 角色设定：至少 3 个英雄和 MVP 敌人有可实现设定。
8. 发布安装：玩家能从 GitHub 安装并配置 Provider。

## 7. 需求追踪规则

1. 所有进入 coding 的功能都必须有 `REQ-*` ID。
2. 每个 `REQ-*` 必须能追溯到一个模块策划案。
3. 每个 `REQ-*` 必须有验收标准和证据类型。
4. 完成后必须把状态改为 `done` 并补证据路径。
5. 没有进入需求追踪矩阵的内容不作为本轮实现范围。
